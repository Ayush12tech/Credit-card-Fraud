# Credit-card-Fraud
Credit card fraud detection is the process of identifying unauthorized or suspicious transactions. Fraudulent transactions are very rare compared to normal transactions, making this a classic imbalanced classification problem.

We use techniques like:

Data preprocessing

Feature scaling

Machine learning models (like Logistic Regression, Random Forest, etc.)

Evaluation metrics suited for imbalance (e.g., F1-score, ROC-AUC, Precision-Recall)
